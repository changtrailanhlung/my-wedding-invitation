Đăng nhập quản trị

Trang này lưu thay đổi thẳng vào kho GitHub của thiệp. Chỉ người có token của bạn mới đăng được nội dung mới. Khách mở trang này sẽ không sửa được gì.

  1. Mở GitHub, vào Settings → Developer settings → Personal access tokens → Fine-grained tokens, bấm Generate new token.
  2. Ở mục Repository access, chọn Only select repositories rồi chọn my-wedding-invitation.
  3. Ở mục Permissions → Repository permissions, đặt Contents là Read and write.
  4. Tạo token, sao chép rồi dán vào ô dưới đây.

Token chỉ được lưu trong trình duyệt của bạn. Đừng đăng nhập trên máy dùng chung.
